# Iwoho Visuals (Fabric 1.20.1)

Визуальный клиент-мод: плавное меню (RSHIFT), настраиваемый HUD с редактором позиций,
теги над игроками (ник, HP, броня, предмет в руке), Target ESP, пресеты шейдеров через Iris,
Lite-режим для слабых ПК.

## Сборка через GitHub
1. Создай репозиторий и залей содержимое папки (включая `.github`).
2. Вкладка **Actions** → *Build Iwoho Visuals* → дождись завершения → внизу артефакт **IwohoVisuals-jar**.
3. Для релиза: `git tag v1.0.0 && git push --tags` — jar появится в Releases.

## Установка
Fabric Loader 0.15+, Fabric API 0.92.2+1.20.1. Для шейдеров — Iris (+ Sodium).
Скачай шейдерпаки в папку `shaderpacks`, в меню → «Шейдеры» выбери пак для каждого пресета и жми «▶».
Для максимума FPS: Sodium + Lithium + вкладка «Система» → Lite-настройки.
